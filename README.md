# 🌸 Eva Flowers — দৈনিক হিসাব ব্যবস্থাপনা

Eva Flowers ফুলের দোকানের জন্য একটি হালকা, মোবাইল-ফার্স্ট দৈনিক হিসাব ও ব্যবস্থাপনা অ্যাপ্লিকেশন। সম্পূর্ণ ক্লায়েন্ট-সাইড, কোনো সার্ভার বা ডেটাবেস প্রয়োজন নেই — সব ডেটা ব্রাউজারের `localStorage`-এ সংরক্ষিত হয়।

## ✨ বর্তমান ফিচার

- ✅ **আজকের সারাংশ** — জমা, খরচ ও ব্যালেন্স এক নজরে
- ✅ **জমা/খরচ যোগ করা** — তারিখসহ স্বয়ংক্রিয় সংরক্ষণ
- ✅ **সর্বমোট ব্যালেন্স প্যানেল** — সব লেনদেনের সারসংক্ষেপ
- ✅ **ক্যাটাগরি শর্টকাট** — গাঁদা, রজনী, গোলাপ, লেবার, বিবিধ
- ✅ **বাংলা তারিখ প্রদর্শন** — `Intl.DateTimeFormat` ব্যবহার করে
- ✅ **ডেটা সংরক্ষণ** — `localStorage`-এ (ব্রাউজার বন্ধ করলেও থাকে)
- ✅ **টোস্ট নোটিফিকেশন** — প্রতিটি অ্যাকশনের ফিডব্যাক
- ✅ **রেসপন্সিভ ডিজাইন** — মোবাইল ও ছোট স্ক্রিনের জন্য অপ্টিমাইজড
